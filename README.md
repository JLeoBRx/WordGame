# WordGame — Cryptic Faith

Protótipo de jogo de criptograma voltado à educação católica: o jogador
decifra uma frase em símbolos e, ao vencer, lê o parágrafo correspondente do
Catecismo da Igreja Católica.

- **Jogo:** [`cryptic-faith/`](cryptic-faith/) (abra `cryptic-faith/index.html`
  no navegador). Documentação completa em
  [`cryptic-faith/README.md`](cryptic-faith/README.md).
- **Referências visuais:** [`game/`](game/).

HTML, CSS e JavaScript puro, sem servidor. Compatível com GitHub Pages: o
`index.html` da raiz redireciona para o jogo.
