# Fontes

Fontes empacotadas localmente (subconjunto latino, suficiente para o
português), para o jogo não depender de serviços externos:

| Arquivo | Família | Uso | Licença |
| --- | --- | --- | --- |
| `fredoka-latin.woff2` | Fredoka (variável, 400–700) | títulos, botões, letras do criptograma | SIL OFL 1.1 (`fredoka-OFL.txt`) |
| `nunito-latin.woff2` | Nunito (variável, 400–800) | textos da interface | SIL OFL 1.1 (`nunito-OFL.txt`) |
| `lora-latin.woff2` / `lora-italic-latin.woff2` | Lora (400–600) | leitura do Catecismo e reflexão | SIL OFL 1.1 (`lora-OFL.txt`) |

Origem: Google Fonts. Se uma fonte não carregar, o CSS usa fontes do sistema.
